# Implementation

1. Project harness and real Next.js/TypeScript/Tailwind/shadcn foundation.
2. Runtime evidence contract and hash-checked local importer, no capture publication.
3. Approved hero/workspace, comparison, full audit, inspector, method, accessible chart, themes and print.
4. Bounded router and read-only Bitget venue context with explicit failure states.
5. Permission-aware export.
6. Tests, lint, types, build, dependency audit, publication scan and approved UI testing.

Commands: `npm run lint`, `npm run typecheck`, `npm test`, `npm run build`, `npm run scan`, `npm audit`.

No public evidence without rights, deployment without approval, reserved-data access, outcome tuning, unapproved merge/narration/submission. The empty remote needs a committed base before a PR; do not silently publish everything to main as a workaround.
